# Notes-on-conceptual-mathematics
I am an eager Mathematics fan that likes to play around with concepts and tries to link them. I use AI assisted formalization while learning to formalize myself. This repository is mainly for making my ideas public so people can interact with it while im trying to learn and validate my ideas myself. 
Each presented Idea has the following attached files : 
1. A README Note ,  explaining the conceptual claim behind the formal intuition. 
2. A Formalization Attempt , using AI assisted writing and research I did myself combined to present the idea 
3. A Correction Note, documenting exactly what mathematically failed in the Formalization, presenting the development of the idea. 
4. A Cross Comparison with other Notes Showing how they the note the Idea relates to other notes I made. Possibly inspiring me to build a new one 

Documents will refer to each other. This page welcomes Interactions and Ideas. 

The mantra for running this page is: 
"No Idea is wrong only its representation. Then the Question only becomes, how to extract the area where it becomes useful and is it worth it in your opinion?"

Have fun with this
I certainly am having fun:)
